Temporal hintsRDNA 3 / RDNA 3.5
RDNA 3 and RDNA 3.5

SLC: 0 = regular; 1 = stream (non-temporal), for graphics-client caches. SMEM operations use SLC=0.

DLC: 0 = regular; 1 = non-temporal, for MALL / Infinity Cache where present; ignored if that cache is absent.

These are the documented control meanings; they do not establish identical cache hierarchies or replacement behavior.

RDNA 3: ISA p.45 · ISA p.46 RDNA 3.5: ISA p.46 · ISA p.47

RDNA 4

Field: three-bit TH, with load/store-specific policies.

Policies include: regular, non-temporal, and high-priority temporal. Atomic RMW uses TH[1] for the temporal hint.
